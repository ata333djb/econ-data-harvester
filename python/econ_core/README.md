## 1. 失业率：两条口径，一条停更、一条起点晚（2026-09 实测）

| 序列 | 所在树 | 取数参数 | 观测范围（实测） | 缺失分类 |
|---|---|---|---|---|
| 城镇登记失业率 (%) | 年度树 `code=3` | `cid=19839dbd8e82481b9524f031c6d816c5` / `id=456ef2f3d75f472b930384237bc6100f` / `root_id=71d41888d5a44bb2a67402ef4e60003e` | 2015-2021；2022/2023/2024 的 `v` 是**空串** | `discontinued` |
| 全国城镇调查失业率 (%) | **月度树** `code=1` | `cid=ee3b7046b390415b9b7745e3d16f6052` / `id=3888eac6062945a79c8a27e5f13d4953` / `root_id=3c9c459384c74f578f3541b2198aac70` | 2018-01 起（请求 2017 起也只回 2018+） | `series_start` |

登记失业率实测值（%）：`2015=4.1  2016=4.0  2017=3.9  2018=3.8  2019=3.6  2020=4.2  2021=4.0`，**2022 起为空**。

调查失业率（月度 -> 年均值，%）：`2018=4.933  2019=5.150  2020=5.617  2021=5.117  2022=5.583  2023=5.217  2024=5.117`。

**为什么必须记住这两件事**

1. **登记失业率 2022 起停更**，属"制度下线"：`missing.classify_missing` 判为 `discontinued`，
   建议动作 `leave_null`。⚠️ **不要对它外推填补** —— 那不是补数据，是伪造数据。
2. **调查失业率只在月度树里**。年度树 13 个"失业"节点只有登记失业率 + 一堆失业保险基金项；
   要拿调查失业率必须走 `code=1` 并按年聚合（`tools/compare-unemployment.py` 取 12 个月算术平均，
   并输出参与平均的月数）。
3. 因此任何"中国失业率"年度序列都要**显式声明口径**：两条线相差 1.1-1.6 个百分点（登记更低）。
   IMF `LUR`/CHN 与**调查**口径几乎重合（实测 ±0.05 pp 以内），不是登记口径。

相关工具：`econ_core/missing.py`（缺失分类器）、`tools/compare-unemployment.py`（三方对比）、
`tools/scan-missing.py`（全量缺失扫描）、`tools/run-all-checks.py`（门禁）。
